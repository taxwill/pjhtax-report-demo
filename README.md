# 경영보고 합성자료 데모

병의원을 가정한 합성자료로 구성한 공개 미리보기입니다.

이 저장소에는 웹브라우저에 제공되는 빌드된 정적 파일만 포함합니다. 원본 개발 저장소, 실제 고객자료, 환자 정보, 인증 기능 및 고객 API 서버는 포함하지 않습니다. 위하고나 금융기관에 연결되어 있지 않으며 실제 고객 보고서가 아닙니다.

소개 화면과 샘플 보고서는 가입 없이 열람할 수 있습니다. 사무소 홈페이지, DNS 및 기존 서버와 분리하여 제공합니다.

Pretendard 폰트의 라이선스는 `fonts/LICENSE.txt`를 참조하십시오.
